Docker disk usage (images, volumes, writable layers, build cache, logs) was not captured on {{ snapLabel }}. 125 images and 64 containers were counted.
Each byte is counted once: image layers are shared between containers and counted under Images only; writable layers hold per-container changes. Database storage lives in named volumes; container logs are JSON files under the Docker root. All of this is part of /dev/sda1’s used space. Logical size (apparent) and allocated size can differ for sparse files and small files; allocated size is what consumes capacity.
